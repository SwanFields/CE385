ข้อ 1: ระบบตรวจทะเบียน
ฝึกใช้ Callback โดยรับ error ไว้เป็นพารามิเตอร์แรก
- ถ้าลืมตรวจ error แล้วอ่าน .name ทันทีโปรแกรมจะพังเพราะค่า student จะเป็น undefined
- ต้อง return หลังเรียก callback เพื่อให้ฟังก์ชันหยุดทำงานแค่นั้นเพื่อไม่ให้โค้ดด้านล่างถูกรันต่อจนเกิดบั๊กง้าบ

ข้อ 2: แปลง Callback เป็น Promise
แปลงฟังก์ชันจากข้อ 1 ให้อยู่ในรูปแบบ Promise โดยใช้ .then() ส่งต่อข้อมูลและใช้ .catch() จับ Error ที่จุดเดียวง้าบบ

ข้อ 3: รายงานฉบับ Async
เขียนโค้ดแบบ async/await เพื่อให้อ่านง่ายขึ้น
- แบบดึงทีละคน for...of + await จะใช้เวลาประมาณ 900ms 
- แบบดึงพร้อมกันจะลดเวลาเหลือเพียงประมาณ 300ms เท่านั้นนน
- try-catch ครอบ await ได้เพราะ await ทำให้ฟังก์ชันหยุดรอ เมื่อ Promise ล้มเหลว error จึงระเบิดตู้มมมในบล็อก try ทำให้ catch ดักไว้ได้ทันที
- ถ้าลืม await หน้า Promise.all โค้ดจะทะลุผ่านไปเลยและได้ค่าเป็น Promise ว่างๆเอาไปใช้งานต่อไม่ได้และเวลาที่ใช้จะกลายเป็น 0-1 ms เท่านั้นง้าบ 

ข้อ 4: เลือก Combinator ให้ถูกงาน
- ใช้ Promise.all เพราะหน้าเว็บขาดอะไรไปอย่างนึงไม่ได้ง้าบ ถ้าพัง 1 อันต้องรีเจคทั้งหมด
- แจ้งผลสอบใช้ Promise.allSettled เพราะต้องการรู้ผลของทุกตัว ถึงจะมีบางตัวพังก็ไม่ทำให้ตัวอื่นหยุดทำงานง้าบ
- Mirror Server ใช้ Promise.any เพราะเราต้องการแค่ข้อมูลจากเซิร์ฟเวอร์แรกที่ผ่านและข้ามเซิร์ฟเวอร์ที่พังไปง้าบ
- ค้นหา Timeout ใช้ Promise.race เอาตัวจับเวลามาแข่งกับการดึงข้อมูล ถ้าหมดเวลาก่อนจะได้สลับไปใช้แคชเก่าแทนง้าบบบบ
